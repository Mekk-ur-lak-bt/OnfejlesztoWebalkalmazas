    How to use

    Users can create daily tasks by category, earn XP and Coins on completion, level up, and track progress on a visual statistics dashboard. The application includes a gamified todo list, a scoreboard, a radar chart for five attributes, a theme selector, a calendar, and a day streak counter. All user data is stored locally via an SQLite database.


    To run the application locally on your machine, make sure Node.js is installed.
    Download the project from github, then open the backend folder in your file maganger.
    Next, open your terminal from this folder, and install the required dependencies by running:
    npm install express better-sqlite3 multer


    Finally, create the database and start the local server by executing:
    node database.js
    followed by:
    node app.js
    Once the server is running, open your web browser and navigate to http://localhost:3000 to launch the application. The database file is created automatically on the first run and persists across server restarts.


    Use Git Bash instead of PowerShell on school computers to avoid execution policy restrictions.
